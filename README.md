# Project Name: Steam Frame Info

## Description:
This is an info page about the new Steam Frame VR headset, including technical specs, a comparison table to other popular headsets with some of their key specs, links to some related info such as reviews, and some pictures that users can swap through by clicking the left and right buttons.

## How to run:
### In VS Code (with the official "Live Preview" plugin)
Clone the repository and open the repo folder in VS Code, then right-click on index.html and click "Show Preview".

### In any browser
Clone the repository and copy the full file path of index.html (should be like 'C:\Users\...\CSC436-Project-1\index.html'), then paste the file path in the address bar and hit enter.
